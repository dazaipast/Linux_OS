# Потоки выполнения

Поток — наименьшая единица, которая выполняет инструкции. Процесс может состоять из одного потока или из многих. Многопоточность означает, что таких потоков несколько. На нескольких ядрах они идут параллельно и не пересекаются. На одном ядре они только делят время: каждый ненадолго получает процессор, и кажется, что программы работают сразу.

У потока, как у процесса, есть контекст: номер, регистры и стек. Отличие в ресурсах. Процессу выделяют собственную память, и для общения с другим процессом нужен отдельный механизм. Потоки одного процесса эту память делят.

Планировщик решает, чей поток сейчас выполняется. В схеме Round-Robin потоки идут по очереди с ограниченным куском времени. Если потоки захватывают ресурсы и вечно ждут друг друга, получается deadlock: ни один не может продолжить.
