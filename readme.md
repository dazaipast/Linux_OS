# Операционные системы и среды

Курс про работу в Linux из терминала. Сначала это файлы, каталоги и процессы, затем виртуальная машина: как сохранить её состояние и как связать с компьютером, на котором она запущена. Дальше оболочка становится инструментом: в одном сеансе держат несколько задач, повторяемые действия описывают функциями, программу собирают через make и оставляют работать в фоне как службу.
