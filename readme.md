## Информация о дисциплине

В дисциплине **Операционные системы и среды** рассматриваются темы по внутреннему устройству и функционированию современных операционных систем.

## Теоретический материал

Теоретический материал дается от простого к более сложному как по общим характеристикам разных операционных систем, так и по конкретным особенностям на примере *ОС Unix* и *ОС Windows*.

В план теоретических занятий входят:

1. **История, назначение, функции и виды ОС**.
   - Студенты вспоминают историю вычислительной техники и узнают процесс возникновения операционных систем.
2. **Структура ОС. Ядро. Процесс загрузки**.
   - Студенты знакомятся с типовой структурой операционной системы, условно поделенной на подсистемы, а также узнают понятие ядра и его роль.
   - Дополнительно показан процесс загрузки операционных систем для архитектуры x86.
3. **Модель процесса**.
   - Студенты разбирают понятие процесса в операционных системах.
4. **Потоки исполнения**.
   - Студенты узнают о потоках как о минимальных единицах выполнения инструкций в ОС.
5. **Межпроцессное взаимодействие**.
   - Студенты знакомятся со стандартными способами взаимодействия процессов между собой.
6. **Организация памяти**.
   - Наиболее сложная тема, связанная с организацией работы виртуальной и физической памяти компьютера и способами разграничения адресного пространства между процессами.
7. **Файловая система**.
   - Студенты знакомятся с функциональностью подсистемы взаимодействия с дисковыми пространствами, таблицами разделов и файловыми системами `FAT`, `NTFS` и `ext4`.
8. **Пользовательское пространство**.
   - Студенты узнают о форматах исполняемых файлов и процессе преобразования исходного кода, а также таких объектах пользовательского пространства как библиотеки и архивы.

## Практические задания

> [!NOTE]
> Для выполнения практических заданий используется операционная система *Debian 13 (Trixie)*.

В процессе изучения материала курса студент выполняет следующие практические работы:

1. **Установка операционной системы в *VirtualBox***.
2. **Bash — основы**:
   - Практическая работа по основам работы в командной оболочке **Bash**;
   - ДЗ 1: [Создание снимков ВМ](https://github.com/dazaipast/Linux_OS/tree/hw-17-09);
   - ДЗ 2: [Простые команды](https://github.com/dazaipast/Linux_OS/tree/hw-23-09);
   - ДЗ 3: [Простые команды 2](https://github.com/dazaipast/Linux_OS/tree/hw-18-09).
3. **Bash — администрирование**:
   - Практическая работа по использованию команд администрирования;
   - Практическая работа по использованию общих папок *VirtualBox*;
   - ДЗ 1: [Администрирование](https://github.com/dazaipast/Linux_OS/tree/hw-20-09);
   - ДЗ 2: [Настройка сетевого адаптера](https://github.com/dazaipast/Linux_OS/tree/hw-30-09).
4. **Bash — приложения**:
   - Практическая работа по использованию `apt`, `vim` и `mpv`;
   - ДЗ 1: [Использование консольного мультиплексора `tmux`](https://github.com/dazaipast/Linux_OS/tree/hw-08-10).
5. **Bash — написание скриптов**:
   - Практическая работа по написанию простых скриптов с подстановками;
   - Практическая работа по написанию скриптов с использованием ветвлений и циклов;
   - ДЗ 1: [Создание демонов `systemd`](https://github.com/dazaipast/Linux_OS/tree/hw-daemons);
   - ДЗ 2: [Использование функций](https://github.com/dazaipast/Linux_OS/tree/hw-functions).
6. **GASM — основы**:
   - Практическая работа по основам GNU Assembler;
   - ДЗ 1: [Автоматизация компиляции Unix Makefiles](https://github.com/dazaipast/Linux_OS/tree/hw-make).
